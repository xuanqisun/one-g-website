# ONE-G 万机智能官网

独立的中文商业展示站，使用 GitHub Pages。原有同事官网及产品站不受影响。

## 页面

- `dist/index.html`：首页，支持按钮、键盘与触屏切换产品展示；团队实拍视频。
- `dist/store/index.html`：万机商城，链接已有产品配置页。
- `dist/custom/index.html`：定制中心，仅在本地整理和复制需求。
- `dist/about/index.html`：企业展示与团队技术演示入口。

## 内容边界

- `hello@one-g.example` 是保留示例域名邮箱，未开通，不是有效咨询渠道。
- 无后端、无资料上传、无支付、无登录、无分析追踪，不保存表单数据。
- 小背包图为概念效果，AI 玩具板卡为产品规划；不表示已量产或可立即交付。
- 遥操全身模式不含三点模式；双模式同时包含二者。三点用户可后续购买升级，增加全身模式和两个脚环。
- 机器人本体不在遥操套装内；夹爪选配，默认沿用 G1 原配橡胶手。
- 商业报价、适配范围、软件授权及交付要求需单独确认。

## 维护与预览

所有页面均为静态 HTML / CSS / JavaScript，无依赖与构建步骤。在 `dist` 中运行一个静态 HTTP 服务器即可预览。

公共资源在 `dist/assets/`，来自用户已有项目与提供的资料；不得将概念图描述为产品实拍。`industrial-design-page-1.png` 是用户指定的《工业设计.pdf》第一页渲染，完整 PDF 未上传。`industrial-design-extended.png` 经内置图像编辑向上下扩展蓝灰色背景，用于首页完整高度展示；原始渲染保留。其作品内标识仅属于原设计画面，不表示客户背书。编辑提示词见 `image-edit-prompt.txt`。

GitHub Pages 使用 `gh-pages` 分支根目录，主分支保留完整项目。发布前验证本地链接、脚本语法、页面导航与表单复制流程。
